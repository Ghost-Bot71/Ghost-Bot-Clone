How to Teach Ghost Bot

The .bby teach command lets you train Ghost Bot to reply to any message. Anyone in the group can teach it new things!

1

Basic teach — single reply

Type: .bby teach hello - Hi there!
Now whenever someone types "hello", Ghost Bot replies "Hi there!"

2

Multiple replies — Ghost Bot picks randomly

Type: .bby teach good morning - Good morning!, Rise and shine!, Morning!
Separate replies with commas. Bot picks one at random each time.

3

Edit an existing teach

Type: .bby edit hello - Hey there, whats up!
Changes the stored reply for "hello".

4

Check stored replies

Type: .bby msg hello to see what replies are stored for "hello".

Examples
.bby teach bhai kemon acho - Valo achi!, Alhamdulillah!, Bhalo thakis tui!
→ Bot picks one random reply when someone says "bhai kemon acho"

.bby teach ghost bot ki - Ami Ghost Bot!, Rakib Islam er bot!, 👻
→ Teaches bot to respond to "ghost bot ki"
1

Teach emoji reactions

Type: .bby teach react good morning - 🌅,😊,👋
Bot will react with one of those emojis when "good morning" is sent.

2

Multiple reactions

Separate emojis with commas. Bot picks one randomly each time.

Reaction Examples
.bby teach react love - ❤️,😍,💕,🥰
→ Reacts with one of those emojis when "love" is sent

.bby teach react funny - 😂,🤣,💀
Manage Commands
.bby remove hello
→ Removes all replies for "hello"

.bby rm hello - 2
→ Removes only the 2nd reply for "hello"

.bby list
→ Shows total teach count and reply count

.bby list all 10
→ Shows top 10 teachers leaderboard

Quick Reference

All BBY Sub-commands

Full list of what you can do with the .bby command.

💬

.bby [message]

Chat with Ghost Bot. It responds using AI and taught responses.

📝

.bby teach [msg] - [reply]

Teach Ghost Bot a new reply. Separate multiple replies with commas.

😍

.bby teach react [msg] - [emojis]

Teach Ghost Bot to react with emojis to a message.

✏️

.bby edit [msg] - [new reply]

Update an existing taught reply.

🗑️

.bby remove [msg]

Delete all replies for a taught message.

📊

.bby list all

See the top teachers leaderboard.

🔍

.bby msg [message]

Check what replies are stored for a specific message.

❓

.bby howto

Shows the full teaching guide directly in Messenger.

🗂️

.bby rm [msg] - [index]

Remove a specific numbered reply from a message.
